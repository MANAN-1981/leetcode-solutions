# Quick Revision

## Pattern Used

HashTable

## Key Idea

The key insight is to use a hash table to store the jewels for efficient lookups. This allows us to quickly check if a stone is a jewel or not.

## Important Observations

Critical observations include the fact that the hash table allows for O(1) lookups, the algorithm has a linear time complexity, and the space complexity is O(n) where n is the number of jewels.
