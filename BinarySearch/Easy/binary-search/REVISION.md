# Quick Revision

## Pattern Used

BinarySearch

## Key Idea

The key idea is to repeatedly divide the search interval in half until the target element is found. This allows us to find the target element in logarithmic time.

## Important Observations

The array must be sorted, the search interval must be updated correctly, the algorithm must handle the case where the target element is not in the array
