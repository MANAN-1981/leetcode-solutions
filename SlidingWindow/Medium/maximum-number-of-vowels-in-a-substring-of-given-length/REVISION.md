# Quick Revision

## Pattern Used

SlidingWindow

## Key Idea

The key insight is to use a sliding window approach to efficiently track the vowels in the current substring. This approach allows for a time complexity of O(n), making it efficient for large strings.

## Important Observations

Critical observations include: the need to update the running count correctly, the importance of handling edge cases properly, and the use of a set to efficiently track vowels.
