# Two Sum

**Difficulty:** Easy
**Topic:** Array
**Language:** Java
**LeetCode link:** https://leetcode.com/problems/two-sum/

## Approach

The code iterates through all possible unique pairs of numbers in the input array using nested loops. For each pair, it checks if their sum equals the target value. If a matching pair is found, their respective indices are immediately returned.

## Complexity

- Time: O(n^2)
- Space: O(1)
