# Quick Revision

## Pattern Used

SlidingWindow

## Key Idea

The key idea is to use a sliding window to efficiently calculate the sum and average of each subarray. This approach allows us to avoid recalculating the sum from scratch for each subarray.

## Important Observations

Important observations include: the sum of each subarray can be updated in constant time, the average of each subarray can be calculated in constant time, and the maximum average can be updated in constant time.
