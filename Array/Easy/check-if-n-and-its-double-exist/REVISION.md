## Key Idea

The key idea is to check all possible pairs of numbers in the array to find a pair where one number is double the other. A more efficient approach is to use a hash table to store the numbers and check for their doubles in constant time.

## Important Observations

Critical observations include: the array can have duplicate elements, the array can have negative numbers, the array can have zero, the array can have a single element.
