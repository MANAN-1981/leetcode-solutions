# Quick Revision

## Pattern Used

SlidingWindow

## Key Idea

The key insight is to use a sliding window technique to efficiently consider all possible sequences of consecutive ones. This technique allows the algorithm to iterate through the array only once, reducing its time complexity to O(n).

## Important Observations

critical observations include the need to reset the count when encountering a zero, the importance of updating the maximum count correctly, and the need to handle edge cases properly
