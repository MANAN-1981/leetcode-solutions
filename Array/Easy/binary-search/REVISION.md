# Quick Revision

## Pattern Used

BinarySearch

## Key Idea

The key insight behind binary search is that the array is sorted, allowing us to eliminate half of the search interval at each step. This reduces the number of comparisons needed to find the target element.

## Important Observations

Critical observations include: the array must be sorted, the search interval must be updated correctly, and the algorithm must terminate correctly when the target element is not found.

## Interview Tips

When explaining binary search in an interview, be sure to emphasize the importance of the array being sorted, the process of updating the search interval, and the termination condition. Practice explaining the algorithm step-by-step and be prepared to answer questions about edge cases and time complexity.
