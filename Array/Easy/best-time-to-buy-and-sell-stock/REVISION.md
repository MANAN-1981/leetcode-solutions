# Quick Revision

## Pattern Used

Greedy

## Key Idea

The key insight is to always choose the minimum price seen so far to guarantee the maximum profit. This is because the minimum price will result in the maximum profit when subtracted from the current price.

## Important Observations

Critical observations include: the algorithm only needs to iterate through the array once, the minimum price seen so far is always the best choice, and the maximum profit is calculated by subtracting the minimum price from the current price.
