# Quick Revision

## Pattern Used

BinarySearch

## Key Idea

The key idea is to repeatedly divide the search interval in half until the target element is found. This reduces the number of comparisons needed to find the target element, resulting in a time complexity of O(log n).

## Important Observations

The important observations are: the array must be sorted, the search interval is repeatedly divided in half, and the target element is either found or determined to be not present in the array.

## Interview Tips

To explain this problem in an interview, be sure to mention the time complexity of O(log n) and the fact that the array must be sorted. Also, be prepared to walk through the step-by-step process of the algorithm and explain how it works.
