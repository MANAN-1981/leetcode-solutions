# Quick Revision

## Pattern Used

SlidingWindow

## Key Idea

The key insight is to use a sliding window approach to efficiently iterate over the string and maintain a count of vowels within the current window. This allows for a time complexity of O(n).

## Important Observations

Critical observations include: the use of a hash table for efficient vowel lookup, the importance of updating the vowel count correctly, and the need to handle edge cases properly.
