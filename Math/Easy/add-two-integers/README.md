# 🧠 Approach

This solution uses a straightforward approach to add two integers together. It defines a method that takes two integers as input and returns their sum. The time complexity is constant because it only involves a single arithmetic operation, regardless of the input size.

# 💻 Source Code

```java
class Solution {
    public int sum(int num1, int num2) {
        return num1 + num2;
    }
}
```
