# Quick Revision

## Pattern Used

Greedy

## Key Idea

The key idea is to keep track of the minimum price seen so far and calculate the maximum profit by subtracting the minimum price from the current price. This approach ensures that the algorithm makes the locally optimal choice at each step, which leads to the global optimum.

## Important Observations

Critical observations include: the algorithm has a time complexity of O(n), the algorithm has a space complexity of O(1), the algorithm uses a greedy approach.
